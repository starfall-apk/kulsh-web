# KulshGPT

Веб-чат с моделями Gemini в стиле Material Design 3: тёмная/светлая тема,
переключение языка (RU/EN), вложения (изображения, ZIP, текстовые файлы),
голосовой ввод/озвучка через браузер, история чатов в localStorage,
рендеринг Markdown (таблицы, код, списки и т.д.), автоматическая ротация
API-ключей Google Gemini при ошибках лимита (429).

## Структура проекта

```
kulshgpt/
├── api/
│   └── chat.js          ← серверная функция (Vercel Edge), обращается к Gemini API
├── public/
│   ├── index.html
│   ├── styles.css
│   ├── app.js            ← вся логика фронтенда
│   ├── i18n.js            ← словарь RU/EN
│   ├── lottie.min.js      ← библиотека для анимаций (bundled, без CDN)
│   ├── marked.min.js      ← Markdown-рендерер (bundled, без CDN)
│   ├── assets/logo.png
│   └── lotties/*.json     ← 6 Lottie-анимаций для пустого чата
├── package.json
├── vercel.json
└── README.md
```

## Деплой на Vercel

1. Залей эту папку в GitHub-репозиторий (или используй `vercel` CLI прямо из папки).
2. На [vercel.com](https://vercel.com) — "Add New Project" → выбери репозиторий.
3. Vercel сам определит статику в `public/` и функцию в `api/chat.js` — **build command не нужен**.
4. Перед первым деплоем добавь переменные окружения (см. ниже).
5. Нажми Deploy.

## Переменные окружения (обязательно)

В настройках проекта на Vercel → **Settings → Environment Variables** добавь:

| Имя       | Значение                              |
|-----------|----------------------------------------|
| `APIKEY1` | API-ключ Gemini участника команды №1  |
| `APIKEY2` | API-ключ Gemini участника команды №2  |
| `APIKEY3` | API-ключ Gemini участника команды №3  |
| `APIKEY4` | API-ключ Gemini участника команды №4  |
| `APIKEY5` | API-ключ Gemini участника команды №5  |

Ключи получаются в [Google AI Studio](https://aistudio.google.com/apikey) —
каждый участник команды создаёт свой ключ на своём личном аккаунте Google.

Можно указать от 1 до 5 ключей — сервер сам подхватит только заполненные.
При ошибке 429 (превышен лимит) или 5xx на одном ключе сервер автоматически
пробует следующий по списку, так что для пользователя сайта сбой одного
ключа останется незаметным, пока не исчерпаны все.

**Важно:** после добавления/изменения переменных окружения нужно сделать
redeploy проекта (Vercel не подхватывает новые env-переменные "на лету"
для уже собранного деплоя).

## Модели

Сайт поддерживает переключение между семью моделями Gemini:
`gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-3.5-flash`,
`gemini-3.5-flash-lite`, `gemini-3.6-flash`, `gemini-3.7-flash`,
`gemini-3.8-flash`. Список моделей и их ID заданы в двух местах — их
нужно менять синхронно, если Google изменит имена моделей:
- `api/chat.js` → `ALLOWED_MODELS`
- `public/app.js` → `MODELS`

## Системный промпт

Системная инструкция для модели зашита в `api/chat.js` (`SYSTEM_PROMPT`).
Меняется прямо там — без пересборки фронтенда.

## Хранение истории чатов

Чаты хранятся в `localStorage` браузера пользователя — просто и без
дополнительной инфраструктуры. Если позже понадобится синхронизация
между устройствами, эту часть можно заменить на Vercel Postgres/KV —
вся логика чтения/записи истории сосредоточена в `app.js` в функциях
`loadChats` / `saveChats`, остальной код их не касается.

## Голосовой чат

Голосовой ввод (распознавание речи) и озвучка ответов работают через
встроенные браузерные Web Speech API — бесплатно, без ключей, но
качество и доступность голосов зависят от браузера пользователя
(лучше всего работает в Chrome).

## Локальная разработка

```bash
npm i -g vercel
vercel dev
```

Так функция `api/chat.js` будет доступна локально на `http://localhost:3000/api/chat`.
Для локальной разработки создай файл `.env.local` в корне проекта с теми же
переменными `APIKEY1..APIKEY5`.


## Изменения в этой версии
- Стриминг ответа (SSE) вместо ожидания полного ответа; пустые ответы обрабатываются и показывают понятное сообщение.
- Таймаут 12 с на ключ: при зависании или 429/5xx/403 сервер переходит к следующему ключу, чтобы не упираться в лимит 25 с у Vercel. Стартовый ключ выбирается случайно, нагрузка делится между участниками.
- Ошибка 400/404 для старых моделей показывается как «модель недоступна для текущих ключей».
- Новые настройки: ширина чата, плотность, шрифт, аватарки, имена, меньше анимаций, стикер, автопрокрутка, подсказка, креативность (temperature), свои инструкции.
